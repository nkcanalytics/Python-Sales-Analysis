# 📊 Sales Data Analysis Using Python

## 📌 Project Overview
This project focuses on analyzing sales data using Python. The main objective is to understand sales performance, calculate revenue, identify top-performing products and regions, and generate meaningful business insights.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📂 Dataset Information
The dataset contains 15 sales records with the following columns:

| Column | Description |
|---|---|
| Order_ID | Unique order identification |
| Product | Product name |
| Region | Sales region |
| Quantity | Number of units sold |
| Unit_Price | Price per unit |
| Revenue | Total revenue generated |

## 🔍 Tasks Performed
1. Created a sales dataset using Pandas.
2. Explored the dataset using `head()`, `tail()`, `info()`, and `describe()`.
3. Checked missing values and duplicate records.
4. Calculated revenue using Quantity × Unit Price.
5. Analyzed product-wise sales using `groupby()`.
6. Analyzed region-wise sales.
7. Created visualizations using Matplotlib.
8. Identified the highest-performing product and region.
9. Calculated average revenue and total quantity sold.

## 📊 Key Performance Indicators (KPIs)
- Total Revenue
- Total Quantity Sold
- Average Order Revenue
- Best Performing Product
- Best Performing Region

## 📈 Visualizations
- Product-wise Sales Bar Chart
- Region-wise Sales Bar Chart
- Product Sales Distribution Pie Chart

## 💡 Business Insights
- Identified the product generating the highest revenue.
- Identified the best-performing sales region.
- Compared revenue across different products.
- Analyzed product sales distribution.

## 🏁 Conclusion
This project helped develop practical knowledge of Python libraries used in Data Analytics, including Pandas, NumPy, and Matplotlib.

It demonstrates basic data analysis, revenue calculations, data exploration, and visualization skills.
